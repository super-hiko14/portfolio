トイエバ for Windows

どの画面からでも Alt+Space で呼び出せる、トイエバ の Windows 版です。計算・単位変換・日付・色・パスワード・ToDo・タイマーを、ひとつの入力欄で。

ダウンロード › v1.1.0 · 1.4 MB · Windows 10 / 11 (64 ビット)

インストール

  1. ダウンロードした Toieba.exe を開く 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください (コード署名をしていないため表示されます)。
  2. 「インストール」を押す 管理者権限はいりません。「Windows の起動時に開始する」をオンにしておくと、パソコンをつけたらすぐ使えます。
  3. Alt+Space で呼び出す ほかのアプリがこのキーを使っているときは、自動で別のキーに切り替えて知らせます。キーはトレイのアイコン →「設定」でいつでも変えられます。

「.NET Desktop Runtime が必要です」と出たら、案内に従ってインストールしてください (.NET 10 のダウンロード → 「.NET デスクトップ ランタイム」の x64)。表示には Windows に標準で入っている WebView2 を使います。

使い方

Alt+Space
出す / しまう
Enter
結果をコピーして閉じる (ToDo の追加などは確定)
Shift+Enter
パスワードなどを作り直す
Tab
候補を入れる / 別の解釈に切り替える
Esc
入力を消す → もう一度で閉じる

タイマーが終わると、閉じていても通知と音で知らせます。テーマや言語は入力欄の歯車 (または「設定」と入力) から。中身はブラウザ版と同じページなので、ブラウザ版を更新するとアプリも自動で新しくなります。

アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」から「トイエバ」を選んで、アンインストールしてください。設定や ToDo などのデータも消すか選べます。

データについて

  • アプリの中では super-hiko14.com のトイエバのページを表示しています。
  • 入力した内容・ToDo・ブックマークは、このパソコンの中だけに保存されます (ブラウザ版とは別)。
  • 新しいバージョンがあるかどうか、1 日に 1 回このページの情報を確認します (設定でオフにできます)。
